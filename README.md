# Autonomous SRE RCA Platform

**Evidence-Driven Incident Detection, Root Cause Analysis, Orchestration and Controlled Remediation**

Prometheus | Splunk | Dynatrace | n8n | ServiceNow | PagerDuty | Slack | AWX | Ansible | eBPF | Bash

## Overview

The Autonomous SRE RCA Platform transforms monitoring alerts into validated, correlated and actionable operational evidence.

The platform demonstrates practical SRE engineering across:

- SLI / SLO and error-budget concepts
- MTTR reduction and incident lifecycle management
- Linux and eBPF evidence collection
- Splunk administration and cluster observability
- Prometheus and Dynatrace observability
- n8n incident orchestration
- ServiceNow, PagerDuty and Slack integration
- AWX / Ansible remediation
- CI/CD validation and controlled deployment

## Engineering Flow

Detect -> Validate -> Collect Evidence -> Normalize -> Correlate -> Analyze -> Notify -> Remediate -> Verify
